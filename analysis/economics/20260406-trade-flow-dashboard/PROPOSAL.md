# PROPOSAL: 世界貿易フロー可視化ダッシュボード

**分析タイプ: 探索的分析（EDA）・可視化ダッシュボード**
本分析は因果推論・仮説検証を行わない。観察された貿易フローの構造と傾向の記述にとどまる。

作成日: 2026-04-06
対象期間: 2017年〜2024年（BACI HS17 版）
対象商品: 9商品（農産品4 + エネルギー3 + 金属2）
対象国: BACI 収録全国（200カ国）

---

## 1. リサーチクエスチョン

主要農産品・エネルギー商品・金属について、国・商品・年を軸に**世界の輸入/輸出フローはどのような構造を持つか**。また**輸出国の国際価格と貿易量の間にどのような関係が観察されるか**。

- 問いは因果ではなく「どのような構造か」「どのような関係が観察されるか」に限定する
- ダッシュボードは探索ツールであり、特定の仮説検証を目的としない

---

## 2. 動機・背景

既存の `20260402-ukraine-commodity-cpi` 分析は CPI と資源価格の時系列変化を捉えたが、
**「誰が誰に何を売っているか」という貿易フローの構造**が可視化されていない。

本ダッシュボードにより以下が可能になる:
- 輸出国・輸入国の地理的集中度の確認（例: 小麦輸出の上位5カ国シェア）
- 価格ショック時の貿易フローの変化の観察（例: 2022年のロシア産輸出先の変化）
- 輸入依存度の高い国の特定

対象読者: 食料・エネルギー安全保障に関心を持つ学習者・研究者。YouTube での公開を想定。

## 3. 事前登録（分析軸の固定）

本分析は EDA であるため、以下の「見る軸」を事前に固定する。
結果を見てから商品・国・期間を変更しない。

### 3.1 対象期間

**2017年〜2024年（固定）**
理由: BACI HS17 バージョンのカバー範囲（2017-2024）。2022年のウクライナ侵攻前後を含む。

### 3.2 対象商品（HS 4桁コード）

| カテゴリ | 商品名 | HS4コード | 選定理由 |
|---------|--------|---------|---------|
| 農産品 | 小麦 | 1001 | ロシア・ウクライナが主要輸出国 |
| 農産品 | トウモロコシ | 1005 | 飼料・バイオ燃料。米国・ブラジル集中 |
| 農産品 | 大豆 | 1201 | ブラジル・米国・アルゼンチン集中 |
| 農産品 | パーム油 | 1511 | 食用油最大品目。インドネシア・マレーシア集中 |
| エネルギー | 原油 | 2709 | 世界最大の貿易品目 |
| エネルギー | 天然ガス（LNG含む） | 2711 | ロシア・中東・米国 |
| エネルギー | 石炭 | 2701 | オーストラリア・インドネシア・ロシア集中 |
| 金属 | 鉄鉱石 | 2601 | オーストラリア・ブラジル集中 |
| 金属 | 銅（精製銅） | 7403 | チリ・ペルー集中。EV需要で注目 |

### 3.3 対象国

BACI に収録されている全国（フィルターで選択可能）。
事前に特定国を除外しない。

### 3.4 可視化軸

| 軸 | 単位 | 備考 |
|----|------|------|
| 貿易額 | 千 USD | BACI `v` 列 |
| 貿易量 | 千トン | BACI `q` 列 |
| 年平均価格 | 商品により異なる | World Bank Pink Sheet から集計（小麦・原油等） |

### 3.5 ページ構成（4ページ）

1. **時系列**: 国別の輸出/輸入量・額の推移
2. **Sankey 図**: 輸出国→輸入国のフロー（選択年・商品）
3. **価格 vs 貿易量**: 年平均価格と世界輸出総量の散布図
4. **Choropleth 地図**: 国別の輸出額/輸入額

## 4. スコープ外
